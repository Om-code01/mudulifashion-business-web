# Muduli Fashion — Image Replacement Guide

Place your photos inside the `images/` folder with these exact filenames:

## Hero & About
| File | Description |
|------|-------------|
| `hero-banner.jpg` | Full-screen hero banner (model/brand photo) |
| `about-brand.jpg` | About section portrait photo |

## Collections (3:4 portrait ratio recommended)
| File | Description |
|------|-------------|
| `korean-fashion.jpg` | Korean Fashion collection cover |
| `western-wear.jpg` | Western Wear collection cover |
| `oversized.jpg` | Oversized Fashion collection cover |
| `party-wear.jpg` | Party Wear collection cover |
| `ethnic-wear.jpg` | Ethnic Wear collection cover |

## Product Gallery (3:4 portrait ratio recommended)
| File | Description |
|------|-------------|
| `product-1.jpg` to `product-6.jpg` | Individual product photos |

## Instagram Grid (1:1 square ratio recommended)
| File | Description |
|------|-------------|
| `insta-1.jpg` to `insta-6.jpg` | Instagram-style square photos |

## Tips
- Use JPG or WebP format for best performance
- Hero banner: landscape, at least 1920×1080px
- Product/collection photos: portrait, at least 800×1067px
- Instagram grid: square, at least 600×600px
